This is my MIDI keyboard!
It comes with 8 keyts, 2 octave shift keys, and needs to connect to a computer to work. Left octave shift to go down and right to go up an octave!

I made it with KiCAD for the pcb and Onshape for the enclosure.
It works pretty simple, with  each key being a capacitive touch, and then triggers an interrupt to tell the computer to play a specific note!
